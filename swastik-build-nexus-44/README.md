# Swastik Group

Premium Real Estate Developer in Mumbai.

## Technologies Used

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```sh
   npm install
   ```
3. Start the development server:
   ```sh
   npm run dev
   ```

## Deployment

Build the project:
```sh
npm run build
```
The output will be in the `dist` folder.
